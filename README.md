# Día 7: CSS Básico

## ✅ Objetivo
Aplicar estilos básicos a una página HTML utilizando CSS.

## 🧠 Conceptos aprendidos
- Sintaxis de CSS
- Propiedades básicas:
  - `color`
  - `font-size`
  - `margin`
  - `padding`
  - `box-sizing`
- Organización de carpetas con `/css`
- Enlace del archivo `style.css` desde HTML

- Elegir tipografía y aplicarla
- Agregar márgenes y rellenos a secciones
- Comentar cada bloque de CSS para entender su función
